### ⚙️ **Slash Command Usage**  

#### 🎵 **/play** + _audio name_ or _link_  
- **Audio Name**: The bot will search **YouTube** for the audio name you entered and play the first result.  
  - If the result isn’t accurate, add more specific keywords (e.g., the artist's name).  
- **Link**: The bot supports playing links from the following platforms:  
  - **YouTube**, **SoundCloud**, **Bandcamp**, **Vimeo**, and **Twitch Streams**.  
  - The link can also be a playlist, and the bot will automatically play all tracks in the playlist.  

#### ⏭️ **/skip**  
Skip the currently playing audio.  

#### ℹ️ **/info**  
View detailed information about the server and the bot.
